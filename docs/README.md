reviewed tasks. Start with one computer and one agent connection.

## Read the evidence

[Public source acceptance](PUBLIC-LAUNCH.md) records the published preview's
checks. [Named two-PC acceptance](ASSIGNMENT-VALIDATION.md) and
[client acceptance](CLIENT-VALIDATION.md) describe the versions, scenarios and
limits of earlier runs. These are dated evidence, not promises that every
OS, client or task has passed. Follow the walkthrough's success checks on your
own setup before assigning more valuable work.
